# Projeto-Semana-do-TI

O projeto Clima & Saúde (CS) consiste em uma plataforma online que permite os usuários consultarem os dados climáticos de diferentes localidades e receberem recomendações de saúde personalizadas. Ao informar uma cidade, o site utiliza a OpenWeather API para exibir informações como temperatura atual e condições meteorológicas (chuva, vento, umidade). Além disso, o sistema oferece precauções contra doenças comuns associadas ao clima, como dicas de hidratação em dias quentes e cuidados em dias frios e úmidos.

Nosso principal objetivo com o projeto é fornecer informações climáticas relevantes e recomendações de saúde personalizadas, promovendo o bem-estar dos usuários de acordo com as condições meteorológicas da sua localidade.
